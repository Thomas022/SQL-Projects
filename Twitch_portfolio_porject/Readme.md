# Twitch Data Analysis

SQL project exploring Twitch viewing activity and chat participation using the `video_play` and `chat` datasets.

## Analysis

- Rank games by view count.
- Explore League of Legends views by country.
- Compare video player usage.
- Categorize games by genre.
- Track hourly views in Brazil.
- Calculate chat participation rates by game.

## SQL Skills

Joins, aggregations, `DISTINCT`, `CASE` statements, date functions, and percentage calculations.

## Files

- `Twitch_Portfolio Query` — SQL analysis queries.
- `video_play.csv` — Video viewing data.
- `chat.csv` — Chat activity data.
