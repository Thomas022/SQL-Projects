# Codecademy Learners Data Project

SQL practice project exploring Codecademy learner data using the `users` and `progress` tables.

## Analysis

- Rank the top 25 email domains by learner count.
- Count learners in New York and mobile app users.
- Explore sign-up activity by hour.
- Examine course progress by email domain and for learners in Chicago and New York.

## SQL Skills

Joins, filtering, grouping, counting, sorting, and date functions.
