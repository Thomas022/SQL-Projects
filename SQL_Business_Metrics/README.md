# SQL Business Metrics

SQL practice queries for analyzing sales, revenue, and player activity.

## Analysis

- Track daily orders and revenue.
- Calculate revenue by product and category.
- Explore product reorder rates.
- Count daily active users by platform.
- Calculate average revenue per user and paying user.
- Measure next-day player retention.

## SQL Skills

Joins, aggregations, subqueries, CTEs, `CASE` statements, and date functions.

## Files

- `Advanced_Aggregates` — Sales, product revenue, and reorder analysis.
- `Common_Metrics` — User activity, revenue metrics, and retention.
